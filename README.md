# Cosmetica Clinic — Privacy Policy & Data Deletion

Public-facing policy pages required by Meta App Review for the Cosmetica Clinic Facebook app.

Hosted via **GitHub Pages**.

## Pages

| Page | URL (after Pages is enabled) |
|------|------------------------------|
| Privacy Policy | https://cosmeticaclinicth.github.io/Cosmetica-Privacy-Policy/ |
| Data Deletion Instructions | https://cosmeticaclinicth.github.io/Cosmetica-Privacy-Policy/data-deletion/ |

Paste these URLs into Meta Developer Dashboard → App Settings → Basic:
- **Privacy Policy URL** → Privacy Policy link above
- **User Data Deletion** → choose "Data Deletion Instructions URL" → Data Deletion link above

## Enable GitHub Pages

1. Push this repo to `main`
2. GitHub repo → **Settings** → **Pages**
3. Source: **Deploy from a branch**
4. Branch: `main` / folder: `/ (root)` → **Save**
5. Wait ~1 min, refresh — the public URL appears at the top of the Pages settings page

## Files

- `index.md` — Privacy Policy (English + ไทย)
- `data-deletion.md` — Data Deletion Instructions (English + ไทย)
- `_config.yml` — Jekyll theme config

## Updating

Edit the markdown, commit, push. GitHub Pages rebuilds automatically within ~1 minute.
